# Business Metrics

Track these metrics before positioning the app as a sellable micro-SaaS.

## Activation

- new businesses created
- onboarding completion rate
- first product added
- first order received
- time to first live menu

## Usage

- active businesses
- active city markets
- active business routes
- dedicated Vercel projects, only when a client needs one
- active modules per business
- orders processed
- bookings created
- rentals created
- repeat customers
- pickup slot utilization

## Revenue

- MRR
- trial conversion
- ARPA
- churn
- expansion revenue
- coupon usage

## Operational Value

- GMV processed
- average order value
- orders per business per week
- top products per business
- staff actions per order

## Acquisition Readiness

Before listing on Acquire, Flippa or Microns, prepare:

- clean README and setup docs
- demo tenant and demo admin login
- screenshots or product walkthrough
- analytics dashboard
- customer acquisition story
- churn and retention data
- expenses and hosting costs
- transfer checklist for domains, Vercel, Render and MongoDB
